What is the purpose of a README file?

A README introduces a project and explains how to use it. It often includes setup instructions, features, and guidance for people who want to contribute.

What is the purpose of a wireframe?

A wireframe is a visual guide that represents the skeletal framework of a website. It helps designers and developers plan the layout and functionality before creating the final design.

What is a branch in Git?

A Git branch allows developers to work on different versions of a project simultaneously. It enables collaboration, experimentation, and the ability to manage changes without affecting the main codebase.
